Как установить

  1. Нажмите «Скачать приложение». Если телефон переспросит, подтвердите: Скачать.
    Download · 下载. Если браузер предлагает «безопасную загрузку» через магазин приложений, выберите обычную (普通下载).
  2. Когда загрузка закончится, нажмите на файл PolskiB1B2.apk в уведомлении сверху или найдите его в приложении Файлы → Загрузки.
    File Manager → Downloads · 文件管理 → 下载
  3. Телефон попросит разрешить установку из этого источника: включите переключатель и вернитесь назад.
    Allow from this source · 允许来自此来源的应用
  4. Нажмите Установить. Предупреждение про «неизвестное приложение» — это нормально: поставьте галочку, если просят, и нажмите Продолжить.
    Install · 安装  /  Continue · 继续安装
  5. Готово: значок Polski появится на рабочем столе.

Если не получается

Пишет про «Чистый режим» (Pure mode · 纯净模式)

Это защита на китайской прошивке Xiaomi: ставит только приложения из своего магазина. В окне с предупреждением нажмите кнопку, которая выключает режим или разрешает установку (关闭纯净模式 / 仍然安装). Если окна нет: Настройки → поиск сверху → введите 纯净 (или Pure) → выключить. Если спросит пароль Mi-аккаунта, введите его. После установки режим можно включить обратно.

Нажимаю «Скачать», и ничего не происходит

Скорее всего, сайт открыт внутри Telegram. Нажмите ⋮ вверху справа → «Открыть в браузере» и нажмите «Скачать» там.

«Ошибка при анализе пакета» (解析包时出现问题)

Файл скачался не до конца. Удалите его из «Загрузок» и скачайте заново по Wi-Fi.
