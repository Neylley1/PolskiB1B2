# Polski B1–B2

Страница загрузки Android-приложения: https://neylley1.github.io/PolskiB1B2/

APK лежит в [Releases](https://github.com/Neylley1/PolskiB1B2/releases) под постоянным именем `PolskiB1B2.apk`, кнопка на странице ведёт на `releases/latest/download/PolskiB1B2.apk`. Новая версия:

```sh
cp app-release.apk PolskiB1B2.apk
gh release create v0.6.3 PolskiB1B2.apk --repo Neylley1/PolskiB1B2 --title "Polski B1–B2 0.6.3"
```

Версия и размер на кнопке подтягиваются из последнего релиза.
